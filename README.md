# Battleheim Lion Fury Lag Fix

A Dungeon Rampage Haxe mod that removes the heavy Lion Fury animation which makes the game lag, with an optional static red tint instead.

<!-- drh:show -->

## What it does

Lion Fury (Battlefury) normally plays a large animated effect around the character wearing it, and that effect is what makes the game stutter. This mod stops the game from loading it at all, so the lag cannot happen.

The buff itself is unchanged: same duration, same bonuses, same everything. It applies to every character with the buff, yours and other players'.

## The option

In the game's settings menu, under **Battleheim Lion Fury Lag Fix**, there is one option:

- **Red tint** on (default): the character turns solid red while Lion Fury is active.
- **Red tint** off: nothing is drawn on the character.

You can change it at any time, in town or during a dungeon.
